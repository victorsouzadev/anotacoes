# Quickstart: Extrair e congelar as ferramentas sem uso

1. Antes: contar `imagem_projetos`, `treino_planos`, `treino_atividades`; abrir um projeto de imagem e gerar um molde em PDF.
2. Ensaio com cópia de `data/`: subir `hub-criativo` e `hub-treino`; contagens iguais, projeto abre igual.
3. Produção: `plugins.lock` com os dois; conferir cada card, `/imagens`, `/moldes`, `/bolo-3d`, `/precificacao`, `/treino` e os MCPs antigos.
4. App Windows novo: abrir e salvar um projeto.
5. PR no núcleo removendo o código; CI mais curta.
