# Quickstart: Duplicar e navegar entre páginas

1. `cd frontend && npx ng test` — `page-ops.spec.ts` passa (ids novos, setas remapeadas, ordem).
2. Nota com 3 páginas: Ctrl+PageDown/PageUp troca; Ctrl+Shift+N cria a 4ª.
3. Botão direito na aba 1 → Duplicar: cópia entra como aba 2, "(cópia)". Mover uma seta na cópia não mexe na original.
4. Arrastar a aba 4 para o início: ordem muda e persiste ao reabrir.
5. Excluir uma página → Desfazer: volta no mesmo lugar.
