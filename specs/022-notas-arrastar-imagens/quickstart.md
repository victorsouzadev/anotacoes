# Quickstart: Arrastar imagens para o canvas

1. `npx ng test` — testes de `cascata` e `cabeNoLimite`.
2. Arrastar um JPG grande para o canvas: destaque ao passar, imagem no ponto ao soltar, reduzida.
3. Arrastar três imagens: cascata, todas selecionadas.
4. Arrastar um PDF: aviso, nada entra.
5. No celular, "Inserir imagem" → câmera ou galeria → imagem no centro.
