# Quickstart: Extrair as ferramentas em uso

Para cada ferramenta, na ordem Dieta → Tarefas → Anotação → Finanças → Notas:

1. Antes: contagens das tabelas dela (e totais do painel na Finanças); uma ação pelo app Android, pela web e pelo MCP.
2. Ensaio com cópia de `data/`: subir o plug-in; contagens e totais iguais; rotas legadas respondem igual (`scripts/conferir-rotas.sh`).
3. Produção: merge do `plugins.lock`; repetir o passo 1; nada de novo login ou reconexão.
4. Uma semana sem 404 novo em `/api/*` → PR no núcleo removendo o código da ferramenta.

Notas, além disso: editar offline no celular, fazer o deploy, voltar a rede e conferir que a edição chegou.
